## 🎯 1. Démarche générale

L’objectif du projet était de reproduire fidèlement une maquette fournie dans Figma en utilisant uniquement **HTML et CSS**.  
J’ai structuré mon travail en suivant ces étapes :

1. Analyse de la maquette section par section
2. Copier-coller le code HTML et CSS de mon travail "composant réutilisable - portfolio"
3. Mise en place des variables CSS (couleurs, typographies, espacements) 
4. Finissions du header en classe
5. Procrastination jusqu'à la veille de la remise 
6. Continuité de la structure HTML avec segmentation en commentaires 
7. Intégration des composants un par un  
8. Ajustements visuels pour respecter plus ou moins la maquette  
9. Documentation du code et création des fichiers README.md et DOCUMENTATION.md  

---

## 🧩 2. Choix techniques

### Structure HTML
- Utilisation de sections clairement identifiées (`<section>`)  
- Commentaires HTML pour segmenter chaque partie  
- Utilisation d’une structure BEM pour garder un code propre  
- Utilisation d’un conteneur `.container` pour centrer le contenu  

### CSS
- Variables CSS dans `:root` pour centraliser les couleurs et tailles  
- Flexbox pour toutes les mises en page   
- Documentation par composant avec commentaires `/* ... */`  

### Composants documentés
- Hero  
- À propos  
- Produits 
- Heures d’ouverture  
- Témoignages  
- Équipe  
- Prix  
- Contact (Nous joindre)
- Localisation
